| 역할 | 이름 | 하는 일 | 산출물 |

| 장표 | | 20분 발표 PPT(개요, 구성도, 보안 설계, 기술, 시연, 역할) | PPT |

| 시연 | | 조원 계정에 `infra/customer-role.yaml` 배포·연결 검증, 시연 리허설, 대체 영상 녹화 | 시연 영상 |
